## ⚠️ **常见问题排查**

### 问题1: 模块导入失败

**错误信息**:
```
ModuleNotFoundError: No module named 'sdwan_desktop'
```

**解决方案**:
```bash
# 确保在正确的目录
cd d:\ai-missions\deepseek\sdwan_diagnostic_platform

# 检查src目录是否存在
dir src\sdwan_desktop

# 重新安装（如果需要）
pip install -e .
```

---

### 问题2: Traceroute超时

**现象**:
```
Traceroute执行时间过长（超过60秒）
```

**原因**:
- 网络延迟高
- 防火墙阻止ICMP
- 目标主机不可达

**解决方案**:
- 减少max_hops参数（从8改为5）
- 减少timeout参数（从3改为2）
- 或使用简化版验证（方法1）

---

### 问题3: 置信度过低

**现象**:
```
置信度: 0.20
```

**可能原因**:
- 路径太短（只有2-3跳）
- 缺少AS号信息（未安装GeoIP2）
- 缺少Hostname信息

**解决方案**:
- 安装GeoIP2数据库
- 增加Traceroute跳数上限
- 这是正常现象，低置信度也有参考价值
