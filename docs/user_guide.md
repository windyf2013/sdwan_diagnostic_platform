# SD-WAN 桌面诊断专家 - 用户手册

## 1. 安装指南

### 1.1 系统要求
- **操作系统**: Windows 10 (64-bit) 或 Windows 11
- **内存**: 至少 4GB RAM
- **存储空间**: 至少 500MB 可用空间
- **网络**: 稳定的互联网连接（用于更新和云端诊断）

### 1.2 安装步骤
1. **下载安装包**: 从官方发布页面下载 `sdwan-diagnostic-setup.exe`。
2. **运行安装程序**: 双击安装包，按照向导提示完成安装。
   - 建议勾选“添加到系统环境变量”，以便在命令行中使用 `agentctl`。
3. **启动应用**: 
   - **GUI模式**: 在开始菜单搜索“SD-WAN桌面诊断专家”并启动。
   - **CLI模式**: 打开命令提示符（CMD）或 PowerShell，输入 `agentctl --help`。

## 2. 快速开始

### 2.1 首次使用
启动 GUI 后，您将看到五个主要标签页：
1. **网络工具**: 提供 Ping、DNS、Traceroute 等基础工具。
2. **一键体检**: 自动检测本地网络配置与连通性。
3. **深度诊断**: 针对特定 CPE 设备进行深度排查。
4. **业务监测**: 模拟浏览器访问，生成 Waterfall 时序图。
5. **报告预览**: 查看和导出历史诊断报告。

### 2.2 执行一次快速体检
1. 切换到 **“一键体检”** 标签页。
2. 点击 **“开始体检”** 按钮。
3. 等待进度条完成，系统将自动展示检测结果表格。
4. 点击 **“保存报告”** 可将结果导出为 HTML 文件。

## 3. 功能说明

### 3.1 网络工具集
该模块提供了一系列常用的网络探测工具：
- **Ping**: 测试目标主机的连通性与延迟。支持自定义发包次数和超时时间。
- **DNS**: 查询域名的解析记录（A, AAAA, CNAME 等）。支持指定 DNS 服务器。
- **TCPing**: 测试 TCP 端口的连通性，适用于禁用了 ICMP 的环境。
- **Traceroute**: 追踪数据包经过的路由节点，帮助定位网络瓶颈。

**操作提示**: 在“目标地址”栏输入 IP 或域名，选择对应工具后点击“执行”。

### 3.2 一键体检 (Quick Check)
一键体检会自动执行以下检查：
1. **系统信息采集**: 获取网卡状态、IP 地址、默认网关及 DNS 配置。
2. **网关连通性**: 测试到本地网关的 RTT 和丢包率。
3. **DNS 解析能力**: 验证国内主流 DNS 服务器的响应情况。
4. **互联网连通性**: 分别测试国内和国际典型目标的可达性。
5. **DNS 分流检测**: 识别是否存在国内外解析不一致的情况。

**报告解读**:
- **严重程度**: 红色代表严重问题，黄色代表警告，绿色代表正常。
- **根因分析**: 详细列出导致问题的具体原因及置信度。
- **诊断建议**: 提供可执行的修复建议（如修改 DNS、检查物理连线等）。

### 3.3 深度诊断 (Deep Dive)
深度诊断用于排查复杂的 SD-WAN 组网问题：
- **CPE 连接**: 通过 SSH 连接到 Cisco SD-WAN 或 Raisecom MSG5200 等设备。
- **拓扑发现**: 自动绘制 Overlay 隧道状态及底层链路信息。
- **配置对比**: 检查设备配置与基准配置的差异。

**注意**: 使用前请确保已在配置文件中正确填写设备的 SSH 凭据。

### 3.4 业务监测 (Waterfall)
该模块模拟真实用户的浏览器行为：
- **URL 监测**: 输入业务 URL，系统将自动加载页面并记录所有资源请求。
- **时序图分析**: 以瀑布流形式展示 DNS 查询、TCP 握手、TLS 协商及内容下载的耗时。
- **性能瓶颈定位**: 自动标记渲染阻塞资源和慢速请求。

## 4. 常见问题 (FAQ)

**Q: 为什么一键体检显示“网关不可达”？**
A: 请检查您的物理网线是否插好，或者 Wi-Fi 是否已正确连接。也可以尝试在命令行执行 `ping <网关IP>` 进行二次确认。

**Q: 深度诊断时连接 CPE 失败怎么办？**
A: 请确认以下几点：
1. 您的电脑与 CPE 之间网络通畅。
2. `configs/commands/cisco_sdwan.yaml` 中的用户名和密码正确。
3. CPE 设备已开启 SSH 服务且防火墙未拦截 22 端口。

**Q: 导出的 HTML 报告无法在浏览器中打开？**
A: 请确保您使用的是现代浏览器（Chrome, Edge, Firefox）。如果报告包含大量数据，加载可能需要几秒钟。

**Q: 如何更新软件版本？**
A: 请访问官方发布页面下载最新的安装包，覆盖安装即可。配置文件通常会被保留。

## 5. 术语表

| 术语 | 解释 |
| :--- | :--- |
| **CPE** | Customer Premises Equipment，客户前置设备，即部署在您现场的 SD-WAN 路由器。 |
| **RTT** | Round-Trip Time，往返时延，指数据包从发送到收到回应的时间。 |
| **Overlay** | 叠加网络，指在现有物理网络之上构建的逻辑隧道网络。 |
| **DNS Split** | DNS 分流，指根据域名来源地返回不同 IP 地址的技术，常用于加速跨境访问。 |
| **Waterfall** | 瀑布流图，一种可视化网页加载过程中各资源耗时的图表。 |
